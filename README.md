# 프로젝트: 아카데미아 팀 위키

별도 빌드 과정 없이 정적 호스팅에 올릴 수 있는 HTML/CSS/JavaScript 위키입니다.

## 로컬에서 보기

`index.html`을 직접 열거나 이 폴더를 정적 웹 서버로 실행하세요. 배포할 때는 폴더 전체를 그대로 업로드하면 됩니다.

## 콘텐츠 수정

- 캐릭터와 스킬 데이터: `assets/js/data.js`
- 전체 디자인: `assets/css/styles.css`
- 검색·필터·상세 렌더링: `assets/js/app.js`
- 게임 소개: `index.html`

웹에서 `guide.html`을 열면 캐릭터 추가 절차와 공개/내부 자료 구분 방법을 볼 수 있습니다.

현재 게임 시스템 내용은 `프로젝트 아카데미아 통합 게임 디자인 문서 v2.3`, 학교·동아리와 과거 작중행적은 `프로젝트_아카데미아 소설_센추리온편`을 기준으로 정리했습니다. 원작소설 1편과 게임 본편의 행적은 캐릭터 문서에서 분리됩니다. 확정되지 않은 캐릭터 프로필과 리소스 사양은 `TBD`, 시스템 후속 작업은 `권장안`, `데모 검증`, `후속 설계`, `그래픽 추가 예정` 상태로 구분합니다.

> 상단의 내부 개발 모드는 보안 기능이 아닙니다. 외부 배포본에서는 `data.js`의 `internal` 데이터를 제거하거나 별도의 공개용 파일로 분리해야 합니다.
