문서 편집 가이드

콘텐츠 파일 하나로 목록·검색·상세 페이지를 함께 관리합니다.

핵심 파일assets/js/data.js의 캐릭터 배열만 수정하면 모든 화면에 자동 반영됩니다.

1. 캐릭터 추가

  1. 이미지 준비이미지를 assets/images/characters 폴더에 넣습니다. 이미지가 아직 없으면 image: null로 두면 이름 이니셜 카드가 표시됩니다.
  2. 데이터 복사assets/js/data.js에서 기존 캐릭터 객체 하나를 통째로 복사해 배열 마지막에 붙입니다.
  3. 고유 ID 지정id는 given-family 형식의 영문 소문자로 작성하고 중복되지 않게 합니다.
  4. 내용 채우기프로필, 작중 행적, 스킬, 장단점, 프로토콜과 리소스 제작 필드를 채운 뒤 브라우저를 새로고침합니다.

3. 공개 자료와 내부 자료

PUBLIC외부 공개

캐릭터 소개, 외형, 성격, 공개된 작중 행적, 스킬 설명, 전용무기와 확정된 프로토콜처럼 팬과 파트너가 읽어도 되는 내용입니다.

INTERNAL내부 개발

캐릭터 코드, 신장·쓰리사이즈, 성우/일러스트레이터 섭외 상태, 아트 제작 사양, 밸런스 메모와 소스 문서 경로를 기록합니다.

4. 기획 상태 표기

확정현재 프로젝트 기준권장안반대 결정이 없으면 채택데모 검증방향은 확정, 수치 조정 예정후속 설계데이터·콘텐츠 설계 필요그래픽 추가 예정디자인 확정, 제작물 대기TBD최신 자료에서 확인할 수 없음

학교·동아리와 원작 시점의 행적은 원작소설 1편을 우선하고, 게임 시스템은 v2.3을 따릅니다. 확인되지 않은 값은 추정하지 않고 TBD로 기록합니다.

5. 내부 모드 주의사항

보안 기능이 아닙니다상단의 ‘내부 개발’ 전환은 화면에서 내용을 구분해서 보는 기능일 뿐입니다. 배포 파일에는 내부 데이터가 그대로 포함되므로 외부 공개본을 배포할 때는 data.js에서 internal과 resource 내용을 제거하거나 별도의 공개용 데이터 파일을 사용하세요.
